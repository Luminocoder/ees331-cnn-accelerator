# 可复用校验工作流

类型：提示词模板与结构化踩坑清单。来源：本项目真实负向测速、相机回放、显示残影和本轮配图复核；交互索引见../docs/ai_collaboration.md。无需PYNQ，不宣称通用PYNQ加分。此文件按路径小写要求命名readme.md，对应指南技能包README说明。

## 1. 固定输入一致性与公平计时

适用：ARM/MCU与硬件核使用相同定点模型，可获得输入张量、完整输出、板端计时器及环境配置的项目。

方法：先固定模型和量化契约，保存输入哈希；逐项比对输出而非仅比较argmax；定义相同起止边界；记录CPU/PL/timer频率、编译优化、缓存和权重准备范围；交替先后顺序、预热、保留原始ticks；最后恢复环境并复核状态。性能表同时保留旧失败版本及资源代价。

可复用提示词：

> 请先列出两个推理路径的输入、输出和计时边界，指出传输、缓存、初始化和量化是否被公平计入；按原始记录逐项核对分数及CRC，再计算正式配对总ticks比值。没有证据的频率、功耗、准确率标为待测，保留负向结果。

已验证效果：本项目130组的全部10路输出及CRC一致；100正式配对得到2.1011倍。原PL慢于ARM的0.1942倍被暴露并保留，推动供数优化。

失效条件：模型/输入不同、不同边界、计时器频率不明、缓存条件不等、正式数据被选择性删除时不能比较；换平台后需要重新核实寄存器与计时器，未验证通用自动化。

## 2. 相机误识别的分层回放

适用：预处理可保存原图、ROI、前景、实际模型张量和原始分数的分类系统。

方法：先检查实际输入是否完整，再对同一张量比PC与板端输出；数值一致后比较同一原图在不同预处理下的尺度、边缘和质心。修改仅依赖图像，不能按已知标签直接改类别；开发集之外另收独立测试集并报告拒绝率。

可复用提示词：

> 请沿原图→ROI→前景→实际输入→10路分数逐层定位差异；保证处理前后是同一原图。区分计算不一致与输入分布变化；列出修改前后保留与改变的条件，说明哪些样本参与过调参。

已验证效果：历史25数字开发回放中3例8/3问题在质心修正后改善，另22例未退步；当前单/双字保存输入可追溯。不是独立准确率结果。

失效条件：只剩预测字符串、原图/张量丢失、预处理版本不明、场景光照或字体显著变化时，历史改善不能直接迁移；不能据此宣称通用OCR。

## 3. 部署和显示证据分级

适用：需厂商工具初始化、串口握手、外设ACK和实物可见输出的软硬件系统。

方法：先校验资源身份，再检查部署退出码、固件握手和能力；保留每一步失败日志。显示协议ACK与实物目视分开记录，扫描换位加入全灭消隐；重绘结构图标明来源，统计图注明原始输入、样本量和边界。

可复用提示词：

> 请为每项结论列出证据层级：源码支持、仿真通过、实现报告、真实协议应答、实物观察。指出哪一层仍缺失，不将ACK替代可见结果，也不把历史构建状态覆盖成新测试结果。

已验证效果：一键初始化由哈希/JTAG/HELLO多层确认；八位分页获得ACK，消影由现场反馈确认。配图复核纠正零边界和量化损失说明，最终保留三处实物照片待补。

失效条件：设备电气极性、扫描周期、厂商运行库或工具版本改变时须重新验证；未知端口不能写死，资源哈希一致也不证明所有功能均正确。跨机和跨板复用尚未独立实测。

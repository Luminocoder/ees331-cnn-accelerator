# 来源与协作

本项目由三人协作完成，GitHub集成与板级验证由费浩轩（Luminocoder）维护。原有团队材料中的成员称呼未提供公开姓名，本仓库不替其补造姓名或重新归属贡献。

- 模型/算法成员：参考模型、训练/量化、原始模型参数，以及`extras/peer_mlp`独立训练与前处理实验。
- RTL/显示与界面协作者：CNN/显示模块、前端页面与双数字接口等原始交付；具体文件保留原内容。
- 集成维护：PC与板卡链路、一键JTAG初始化、相机输入/回放、连续拍摄/分页、ARM对照及卷积优化、实板验证、最终整理。AI协助过程另见ai_collaboration.md。

当前源码来自实测v5.6整合目录；所有复制件及原路径、大小和SHA256见`provenance/copy_manifest.json`。文件名小写化不改变产品源码/权重/RTL内容；两处测试入口的路径适配另有原件和哈希记录。保留原说明和历史构建记录用于追溯，不将封存时“待上板”覆盖后来真实测试。

MLP与硬件CNN明确分开；`hardware/pl/rtl/cpu/driver.c`及旧axi_if.v等为原参考代码，实际部署ARM入口是`hardware/arm/fw_seg.c`，SoC使用axi_if_v2.v。参考资料的存在不表示它是当前执行入口。

# 许可与第三方组件

本次按用户授权公开代码以供竞赛检查与复现。原项目未指定统一开源许可证，本次整理不替全体贡献者授予新的版权许可；代码版权仍归原贡献者。公开可浏览不等于已满足某一特定开源许可，队伍提交前应确认统一许可证。

依赖许可按原文件保留，见`third_party/`及本地`_internal/`中的许可文件。NumPy、OpenCV、Pillow、Python/Tcl/Tk和PyInstaller分别按其各自条款使用；第三方许可不因仓库公开而被替换。Vivado/LLVM安装程序、USB驱动、完整MNIST数据集均未打包。生成的PS脚本与构建资源用于本板复现，不将其表述为团队原创工具实现。
